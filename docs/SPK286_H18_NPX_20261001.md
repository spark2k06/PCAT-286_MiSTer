# SPK286 H18 integration: CPU-side no-NPX traps

Date: 2026-10-01.

The vendor import implements ESC #NM on MSW.EM || MSW.TS, and WAIT #NM on
MSW.MP && MSW.TS, in real/protected mode at every CPL. Without a fault, WAIT
completes with BUSY inactive. This is CPU-side support in the no-coprocessor
profile; no 80287 arithmetic or external NPX interface is implemented.

The synchronized decoder, executor, microcode source/compiler/generated ROM
and directed tests are documented in
[the vendor H18 report](../vendor/spk286/docs/PROTECTED_MODE_H18_NPX_20261001.md).
The existing vendor real-mode fetch IP-wrap implementation is preserved.
CLTS baseline and privilege banks are included for reproducible local validation.
The decoder test retains exhaustive extended-opcode classification and the
standalone per-entry checks.

Validation enables P01 memory start, P02 fetch chaining and P05 parallel limit
checking together. Six vendor banks pass in both simulators: decoder, NPX
traps, legacy ESC syntax, CLTS, CLTS privilege and event NT. The NPX bank passes
9,079 cases / 58,615 assertions per simulator. Strict vendor lint also passes.

The supplemental physical D8 probe finds 33 pre-existing #GP boundary failures
at offset FFFF, reproduced identically before and after H18. They remain open
under H19; full ESC conformance is not claimed. WAIT passes all 5,000 physical
captures. See the report and receipt for exact source/case identities.
