# P06 target candidate packet

This packet binds the new all-features RBF to its effective source inputs and
retains fitted resources, all reported timing corners, composed-machine results
and completed compatibility records. The manifest describes the standard
build-date macro regenerated during compilation.

The user deferred the full regression. The recovered compatibility records are
partial and are not a complete 26-bank PASS. The exact IOPL fixture subsequently
passed at 6 MHz in Verilator; its separate packet retains the timeout diagnosis.

The tar archive excludes Quartus databases, simulator executables and compiler
objects. Each member was read back and SHA-256 verified before cleanup. Frozen
effective sources are under `source/`; build and timing reports under `fit/`.
The RBF and SOF remain separately in the original fit run's `output_files/`.

See [the candidate summary](../../optimization/P06_TARGET_CANDIDATE_20261005.md)
for behavior, exact validation scope, measured cost, timing limits and RBF path.
