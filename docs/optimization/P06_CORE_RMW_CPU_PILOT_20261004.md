# P06 M6g: private bounded XOR word RMW

Date: 2026-10-04. Directed acceptance and frozen independent audit: PASS.
This follows the frozen
[M6f WRITE milestone](P06_CORE_WRITE_CPU_PILOT_20261004.md). The candidate is
private, with a 6 MHz virtual CPU schedule on the existing fabric clock.
Production config, source selection and selected RBF are unchanged.

## Functional boundary

The qualified instruction is prefix-free Real Mode `81 36 disp16 imm16`:
`XOR word [disp16],imm16`. The original decoder, effective address, READ into
TMP0, immediate into TMP1, ALU result into TMP2, WRITE disposition and final
COMMIT_FLAGS sequence remain the functional path. An aligned reference has
one physical beat; an odd reference has two, for both READ and WRITE.
Original BIU lanes, payload retention and address carry across A16/A20 are
preserved. The BIU generated bytes are identical to M6f.

FLAGS readiness is independent of execution enable. It requires the real
COMMIT_FLAGS phase, valid retained flags and disposed WRITE result. FLAGS and
instruction retirement share the first permitted CPU boundary after those
dependencies complete. The original END tail is skipped at that real commit.
TMP2 becoming valid cannot retire the instruction before its store finishes.
There is no new result buffer, register bank, queue capacity or PLL.

Only ModR/M 36h is newly admitted. Other memory forms, prefixes, LOCK, MMIO,
code modification, offset FFFF and event handling remain outside the qualified
test scope. The private admission guard rejects the unqualified instruction
forms; it does not classify MMIO or self-modifying addresses. Caller vectors
use ordinary RAM, disjoint code/data ranges and offsets below FFFF.
This serialized pilot does not accept historical write-buffer EU overlap.

## Timing and retained form qualification

The [pinned Intel extraction](P06_INTEL_TIMING_REFERENCE_20261003.md) gives
XOR memory/immediate a seven-clock minimum. An odd word reference adds two
clocks; RMW has two references and therefore adds four. Only actual additional
READ waits increment the EU budget. WRITE waits extend the functional bus
dependency without being charged as READ waits.

Opcode 81 initially uses the existing three-clock register/immediate admission.
After consuming 36h, the original retained ModR/M fields identify the bounded
memory form, before EA resolution. This metadata is a level, not an event.
The first following CPU boundary adds four clocks once, producing seven.
Existing READ/alignment eligibility bits retain that qualification. No extra
state bit is introduced. Each accepted odd READ/WRITE Ts separately adds two.

The aggregate minimum is `7 + 4*odd + READ_wait1 + READ_wait2`. It is a lower
bound alongside actual dependencies. The earliest observed serialized cases
retire after eight clocks aligned and twelve odd, so this instruction path
does not make the aggregate seven/eleven-clock minimum binding. The permit
mutation tests boundary enforcement; it must not be presented as proof that
removing only the minimum check would fail this specific workload. Native
86Box and table minima do not establish exact Intel issue/pin phases here.

## Abandonment and ordering

Cancel before WRITE acceptance suppresses that store. Cancel after acceptance
preserves external effects and drains the original retained word halves,
while suppressing FLAGS and retirement. Reset interrupts the backend and can
leave a partial word. Invalid HOLD scope blocks publication until reset; this
is not complete historical HOLD service.

The fixture checks READ before WRITE, original retained payloads, complete
WRITE disposition before FLAGS, mutable RAM on each accepted physical lane,
and untouched adjacent guard bytes. Consecutive A3 writes, a following READ
and EU execution overlapping a retained write remain separate milestones.

## Directed acceptance

The matrix contains 858 caller-defined cases. READ and WRITE waits are
independent, with 0/1/2 waits per beat and early/exact/late physical READY.
Warm/cold fetch, both instruction-address parities, payload and FLAGS patterns,
and A16/A20 carries are included. Architectural vectors include zero, negative
and positive nonzero results with both low-byte parity outcomes.

The lifecycle controls pause at FLAGS, READ/WRITE admission and between odd
beats, and cancel/HOLD/reset at seven boundaries around both operations.
Separate late-response cancellation and three exact-final-WRITE-Tc cases
exercise retained work. Acceptance requires 2,503 timed cases and 67 identical
Icarus/Verilator trace pairs, plus 858 original/private MAX cases each.

Physical lanes, events and commit intent are sampled before each edge;
architecture, scope and caller form-count are sampled afterward. On the first
invalid HOLD edge, a pre-edge form diagnostic can coexist with post-edge scope
and a zero accepted form-count. The audit checks this distinction and permits
no FLAGS or retirement on that invalid edge.

It also requires exact frozen warm/cold A1 READ and A3 WRITE traces with RMW
enabled, and 688 register-stream programs/1,448 instructions per temperature.
The existing register form of 81 must retain its original timing and relaunch.
Nine specific mutants test missing late qualification, alignment or READ waits,
incorrect WRITE wait charging, boundary bypass, early FLAGS, ALU retirement,
wrong READ assembly and wrong WRITE payload. Each must fail its named oracle.

Strict lint covers five configurations. Component checks prove MAX and RMW-off
duration bypass, the actual extracted executor commit fragment and BIU MAX
equivalence, and inspect private-input cones. The executor proof covers that
fragment, not the whole executor or full CPU. Four affected MAX unit benches
and microcode consistency are also required. No total regression is included.
