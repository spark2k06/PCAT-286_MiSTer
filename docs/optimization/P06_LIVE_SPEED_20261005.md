## Safe boundary and retained bytes

The profiled CPU parks execution admission and new internal fetch requests
only between completed instruction/event contexts, including retirement
pulses and historical target-length qualification. Its BIU remains enabled
so existing references and responses can drain. The machine applies the
selection only when the CPU reports ready, the actual AT bridge is idle and
the posted-memory drain signal is clear. The virtual phase epoch restarts
at zero without resetting CPU registers or devices.

Completed prefetched responses need not be empty: requiring that can deadlock
against a full six-byte queue while admission is parked. They retain their
ownership and resume consumption afterward. Historical branch qualification
has already removed target bytes from the native queue, so its replay buffer
must also survive a transition to MAX. Only reset, stream restart or a new
preview epoch clears it; changing timing mode alone does not discard bytes.

The boundary predicate uses registered context indicators. Target pending
already covers an active preview; including the combinational preview-enable
path would feed redirect qualification back into execution admission. Strict
full-CPU lint passes without suppressing that loop warning.
