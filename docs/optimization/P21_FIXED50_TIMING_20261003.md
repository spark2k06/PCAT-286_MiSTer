## SDRAM column separation: verified experiment

The owner admits a new write only while KFSDRAM is IDLE. During READ/WRITE,
the column therefore already comes from the retained transaction address.
Supply that retained column directly to KFSDRAM; keep the live admission
address for the ACTIVE row command. The generic controller's default parameter
preserves its former single-address behavior. No counters, state transitions,
clock edges, data lanes, reset declarations or other pins change.

`scripts/prove_at_sdram_column.py` checks this exact source delta and proves
all 229 comparison points of the actual owner/controller. Internal register
names are preserved; arbitrary intermediate combinational signals are not
cut away from their actual state dependencies. The proof uses `async2sync`
for sampled-clock reset behavior; source guards and directed tests retain the
actual asynchronous reset declarations. Inverting bit zero of the actual
column binding fails the negative control (nine address bits unproven).

Actual pin-model write admission passes 71 writes, 70 reads and 41 refreshes;
dual-simulator owner, read-buffer, entry and capture tests pass. The entry
bench includes burst, stable payload, reset and refresh checks. Eight bounded
CPU firmware traces remain byte-identical, with no new Verilator diagnostics.
The source-bound receipt covers 79 inputs in the fresh snapshot.

## FDC sector preparation: functionally verified timing experiment

selection, drive-indexed geometry and two arithmetic operations before
capturing `logical_sector`. Calculate the sector expression independently for
each of the two drives and place the drive-selection mux after the arithmetic.
The capture condition, capture edge and all registers remain unchanged.

`scripts/prove_fdc_sector_selection.py` extracts the actual reference RHS,

zero, both heads/drives and arithmetic wrap; it requires no legal-geometry or
command-state assumption. A corrupted bit in the actual drive-1 expression
fails the negative control. This is a universal RHS proof plus an exact source
guard, not a whole-module formal proof.

The actual device/router/FDC/DMA integration passes before and after the
rewrite in Icarus and Verilator. Each simulator's run log is byte-identical
to its reference, including a 512-byte DMA sector, page/address sequencing,

unchanged, with location numbers normalized. The source-bound functional

## Bridge retained I/O classification: verified experiment

The remaining admission seed 1 path includes the bridge's live memory-width
qualification before the FDC's I/O decode. Early memory is possible only in
IDLE. Retained transactions are valid only in ADDRESS, COMMAND and WAIT.
Factor the retained-valid predicate explicitly and use it for I/O and INTA
classification. This Boolean identity holds for every binary state value,
including unreachable values. The rewrite adds no registers or cycles and
does not change addresses, payloads, request acceptance or completion.

`scripts/prove_at_bridge_classification.py` guards the exact full-source
delta, then proves the whole actual bridge for both values of
`COMPLETE_ON_CPU_SAMPLE`. All public outputs remain unmasked; internal
matching is limited to actual register bits. Yosys proves 159/159 comparisons
for mode 0 and 143/143 for mode 1. The negative control removes early-memory
exclusion from the actual I/O qualifier and fails specifically at that
public output in both modes. The scope is sampled-clock two-state
synthesizable equivalence, with unchanged asynchronous reset declarations.
An independent review finds no functional blocker.

The A1 bus and response tests pass in Icarus and Verilator. Cancellation
passes in Verilator at both default and production code-buffer geometries.
All six before/after simulator logs are byte-identical. Response lint is

refreshes. Machine lint warning inventories are unchanged after normalizing

## Data-buffer metadata capture: verified experiment

The accepted transaction edge already captures three private metadata bits:
the two lookup-valid flags and the replacement choice. Capture those same
bits on every IDLE edge. The accepted edge and every consuming phase keep
their original values. The capture enable no longer depends on the late
memory request and acceptance decode. Tag/data RAM read enables, RAM writes,
payload capture, state transitions, reset values and public outputs remain
unchanged. No registers, RAM, cycles or clock changes are added.

`scripts/prove_at_data_capture.py` checks the exact source delta and derives
a complete one-step relation from the actual elaborated controller. It
compares all 25 actual registers (1,028 bits) and every original public
output. The three private metadata bits may differ only in IDLE; all other
state must match. A separate reset theorem establishes this relation without
prior equality of those three bits. Unreset lookup registers and RAM use
common arbitrary initial contents as the source-equivalence coupling.

Both actual 256 x 32-bit memories retain every parameter and initialization
descriptor. Their read data are shared arbitrary proof inputs. Memory clocks,
reset, control, enables and addresses are compared completely; each write
data bit is compared whenever its write enable is asserted. This proves
identical memory updates by induction. No original public output is masked,
memory is not downsized, and no external protocol assumption is imposed.
Original port directions/widths, complete FF clock/reset descriptors and
stable source/tool hashes are guarded. A real valid0/valid1 capture mutation
fails SAT with a prior-relation-true, next-relation-false counterexample.
This negative demonstrates sensitivity to an incorrect internal capture;
it does not claim an immediate public-output divergence.

The existing duplicate-tag diagnostic requires a coherent lookup record.
During IDLE, eager metadata can refer to a new live index while tag/data still
refer to the previous accepted index. A directed witness uses only legal reads
at addresses 2, 514 and 0, then changes the idle address with all request
signals inactive. The unqualified assertion fails while there is no bus
acceptance, response or memory side effect. Qualify this one simulation-only
diagnostic to non-IDLE consuming phases. Its checks remain active throughout
LOOKUP and PHYSICAL. The same witness then passes and a following real read
returns the expected cached word, with four acceptances/completions, one hit
and only three physical reads. No private state is forced or deposited.

The actual 512-word unit passes in Icarus and Verilator. Full CPU/DMA/loader
coherence, refresh/burst/reset and production 4 KiB code-buffer pipelines pass
in Verilator. All four run logs are byte-identical to the unchanged baseline;
strict lint is clean with the pre-existing synchronous/asynchronous-reset
waiver and warning inventories unchanged. Independent review approves the
compositional proof and the separately validated diagnostic domain.
The physical outcome is recorded below; no full regression or hardware
validation is claimed.
