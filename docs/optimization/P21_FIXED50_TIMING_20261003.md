## First measured structural changes

- Use the actual MiSTer memory port's registered DMA completion. Formal proof
  of the actual port establishes that acceptance and completion cannot overlap;
  removing acceptance from the completion qualifier is equivalent. The static
  machine parameter preserves compatibility with abstract test backends.
- Decode the six legal prefetch head positions in parallel. The queue retains
  its six bytes, pointers, write logic and all handshake behavior. A source
  guard and SAT proof cover arbitrary contents and legal pointers; the actual
  reset/flush and pointer increment preserve that domain.

Both proofs include failing negative controls. Strict CPU lint, dual-simulator
queue/fetch fidelity and memory-port checks pass. Eight bounded firmware traces
are byte-identical to the reference, including cycles and traffic. The generic
Sound Blaster smoke tests pass but do not exercise active audio DMA; the actual
memory-port proof covers the changed qualifier. No full regression or new
hardware benchmark is claimed.

## SDRAM column separation: verified experiment

The owner admits a new write only while KFSDRAM is IDLE. During READ/WRITE,
the column therefore already comes from the retained transaction address.
Supply that retained column directly to KFSDRAM; keep the live admission
address for the ACTIVE row command. The generic controller's default parameter
preserves its former single-address behavior. No counters, state transitions,
clock edges, data lanes, reset declarations or other pins change.

`scripts/prove_at_sdram_column.py` checks this exact source delta and proves
all 229 comparison points of the actual owner/controller. Internal register
names are preserved; arbitrary intermediate combinational signals are not
cut away from their actual state dependencies. The proof uses `async2sync`
for sampled-clock reset behavior; source guards and directed tests retain the
actual asynchronous reset declarations. Inverting bit zero of the actual
column binding fails the negative control (nine address bits unproven).

Actual pin-model write admission passes 71 writes, 70 reads and 41 refreshes;
dual-simulator owner, read-buffer, entry and capture tests pass. The entry
bench includes burst, stable payload, reset and refresh checks. Eight bounded
CPU firmware traces remain byte-identical, with no new Verilator diagnostics.
The source-bound receipt covers 79 inputs in the fresh snapshot.

Fresh fit: `build/fixed50-sdram-column-fit-20261003`, started after validation
with the same physical clocks, QSF and SDCs. Full compilation completes in
30:02 with zero errors; the subsequent detailed four-model audit completes.

## SDRAM admission selection: verified intermediate milestone

The SDRAM owner can select the live address while `kf_idle && !active_q`,
instead of including the late write-admission qualifier in that address mux.
Only an accepted write consumes the live row address; launched commands keep
the retained transaction address. The `kf_idle` guard also preserves that
retained address after early read completion while the controller is busy.
READ/WRITE columns continue to use the separately retained column binding.
This changes no command acceptance, controller state, reset, clock or cycle.

The whole actual owner/controller proof passes all 229 comparison points;
inverting a bank-address bit at the actual controller binding fails its
negative control. Actual pin-model admission passes 71 writes, 70 reads and
41 refreshes. The dual-simulator owner test passes 22 writes and 20 reads.
Eight bounded firmware traces, including cycles and traffic, are byte-identical
to the preceding column candidate, with no new Verilator diagnostics.
The source-bound receipt covers the 79 inputs used by the frozen fit.

The placement-only seed 3 column variant also completes its four-model audit.
It passes HDMI but has global setup of -0.425/-0.444 ns in the slow models,
with a data-buffer metadata capture path as its limiting path. It is not
selected. No data-buffer RTL changes are part of the retained milestone.
